# Decision Framework

## Objective
Choose the option that best achieves the desired outcome within hard constraints.

## Process
1. Identify hard constraints. Eliminate options that violate them.
2. Select only decision-relevant criteria.
3. Compare genuinely different viable options.
4. Prefer simpler/existing solutions when outcomes are equivalent.
5. Record the material trade-offs.
6. Recommend based on evidence, not novelty or feature count.

## Common Criteria
Use only those that matter:
- solves core problem
- cost
- implementation effort
- reliability
- security/privacy
- maintainability
- operational burden
- integration quality
- flexibility/lock-in
- reversibility
- time to useful result

## For Each Finalist
State:
- gains
- losses
- dependencies
- major failure/regret risk
- what would change the decision

## Recommendation
Return:
- recommended approach
- 3–5 reasons maximum
- confidence: HIGH / MEDIUM / LOW
- assumptions that could change it
- highest-value validation still required
